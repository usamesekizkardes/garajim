# Garajım

Araçların için bakım, belge ve masraf takibi yapan, telefona uygulama olarak kurulabilen bir web uygulaması (PWA).

- Kayıtlar, fotoğraflar ve belgeler yalnızca kullanıcının telefonunda (tarayıcının IndexedDB deposunda) saklanır. Bu depoda kişisel veri yoktur.
- Uygulama içindeki **Veriler → Yedeği indir / Yedekten yükle** ile yedek alınır.
- İnternet olmadan da açılır (service worker).
